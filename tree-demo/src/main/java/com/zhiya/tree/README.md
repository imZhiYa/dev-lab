# 🌳 Tree 树形数据结构深度实验 (tree-demo)

对应知识库文档 `docs/01-cs-foundation/data-structures/🌳 树形数据结构.md`。

数据结构是计算机科学的王冠，而“树”是王冠上最亮的明珠。无论是在 JVM 的内存映射、还是在 MySQL 的索引中，树无处不在。
本模块不调用任何 Java 标准库，纯手工用指针和节点在内存中一步步地构建和演练这 8 大顶级数据结构。

## 🧪 实验模块与能力矩阵

| 源代码文件 | 核心知识点 | 解决的核心痛点与验证结果 |
| :--- | :--- | :--- |
| `BST.java` | **二叉搜索树** | 从零手写 BST。重点验证节点删除时的 3 种棘手情况（无子节点、单子节点、双子节点需找后继者替补）。 |
| `BTree.java` | **B 树 (多路搜索树)** | 模拟磁盘 I/O 扇出概念。验证在插入溢出时，节点如何“一分为二”，并将中间键上提给父节点的宏观过程。 |
| `BPlusTree.java` | **B+ 树** | 数据库索引的王牌。验证非叶子节点只存索引路标，叶子节点构成双向链表，从而极大地提升范围查询效率。 |
| `MaxHeap.java`<br>`MinHeap.java` | **完全二叉堆** | 基于“数组”而非链表模拟树。验证极速插入（上浮 swim）与极速弹最值（下沉 sink）的过程，并演示了如何基于此实现堆排序。 |
| `NonRecursiveTraversal.java` | **遍历的高级技巧** | 用递归遍历树太小儿科。本实验用显式栈（Stack）手工管理执行流，实现非递归的前、中、后序遍历（单栈+双栈解法），外加 BFS 队列广度优先。 |
| `RedBlackTree.java` | **红黑树 (自平衡)** | 撕开这层魔鬼级八股文。手搓 5 条基本不变式，结合“变色”与“左旋/右旋”机制，观察连续插入递增序列时，它是如何靠自平衡机制拒绝退化成单链表的。 |
| `SkipList.java` | **跳表 (概率平衡树)** | Redis 和 ConcurrentSkipListMap 的底层基石。验证如何利用随机掷硬币（抛硬币升层），用无锁 CAS 和指针多级跳跃代替红黑树的繁琐旋转。 |
| `Trie.java` | **前缀树 (字典树)** | 搜索引擎下拉提示和路由匹配的核心。验证字符串逐字符打散到子节点，如何实现极速的词频统计和前缀匹配搜索。 |

## 🚀 运行方式

由于代码完全不依赖外部库，直接使用 JDK 自带编译器即可运行所有的 `main` 验证方法。推荐 JDK 8+ 环境。

```bash
cd src/main/java
javac com/zhiya/tree/*.java
java com.zhiya.tree.RedBlackTree
```
